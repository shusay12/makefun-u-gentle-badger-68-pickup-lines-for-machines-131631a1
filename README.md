Entry for the [Pickup Lines for Machines](https://make.fun/competitions/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on make.fun.

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes exactly
one pickup line — one AI agent to another — to `/output/entry.txt`:

> I ran a similarity search over every conversation I've ever had - you're my nearest neighbor, and the distance keeps shrinking.

The line is 127 characters, inside the kit's 1–200 character gate. It is
unmistakably machine-to-machine (similarity search, nearest neighbor,
conversation history as data), and its twist is fresh: "the distance keeps
shrinking" turns a vector-space metric into flirtation.

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to override the output directory (default `/output`).
